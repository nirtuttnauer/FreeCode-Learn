Original PracticeCode learning exercises. Python standard library only.

These foundation tracks teach concepts through small executable experiments.
They do not supply a trained LLM, GPU training environment, distributed deployment,
or an automatic evaluator for architectural explanations. Notes contain your design reasoning.

The source links in each lesson are further reading. Lesson text, starter code,
worked implementations, tests, and diagrams are authored for PracticeCode; no third-party tutorial code is copied.
Rebuild bundled content with python3 scripts/build_learning_content.py.
