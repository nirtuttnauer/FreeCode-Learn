# Third-party notices

PracticeCode's original app and course code uses MIT. Original teaching prose and
diagrams use CC BY 4.0; see LICENSE-CONTENT.md.

Bundled Python packages retain their upstream license files in their `.dist-info`
directories. `packaging/course-packages-lock.json` records exact distributions,
download URLs and SHA-256 hashes for Python 3.12 on each supported platform.
Python, Node.js, OpenJDK, Zig and Electron retain their vendor notices; runtime
lock files identify the bundled releases. The OpenJDK source archive is included
with the runtime bundle.

The public content profile contains original PracticeCode courses. LeetCode statements,
Doocs reference material, imported playlists and their assets belong to the
personal content profile and are excluded from public source exports and builds.
Their existing notices remain with that private data; the root licenses do not
grant rights over it.
